# Win32Soko
Old sokoban game for Windows32 written in pure x86 asm (Win API)

## Browser remake (Rust / WASM)

A modern browser port lives in [`wasm/`](wasm/):

```bash
cd wasm
trunk serve
```

Or with Docker:

```bash
cd wasm
docker compose up --build
```

See [wasm/README.md](wasm/README.md) for controls and layout.
